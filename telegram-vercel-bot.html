Telegram Vercel Bot

Serverless Telegram bot prototype built to validate webhook delivery and lightweight cloud deployment on Vercel

Tech Stack

Python Vercel Telegram Bot API Serverless Functions JSON Storage Webhooks

Description

Telegram Vercel Bot is a cloud deployment prototype focused on running a Telegram bot through webhook-based execution on Vercel. It tests how bot workflows, user activity tracking, and message-link persistence behave in a lightweight serverless environment without relying on a long-running local process.

Key Highlights

  • Built around webhook delivery and Vercel routing to support cloud-hosted Telegram bot execution.
  • Used lightweight JSON persistence for active-user tracking, message-link mapping, and basic bot state management.
  • Validated environment-based deployment setup for handling runtime secrets and platform configuration cleanly.
  • Served as an infrastructure experiment for low-maintenance bot hosting and rapid deployment iteration.
