Telegram Forwarder Bot

Admin relay bot for managing user conversations, broadcasts, and support flows from a single Telegram interface

Description

This Telegram bot forwards all incoming user messages to an admin, preserves message mappings for replies, supports safe broadcast workflows, and adds admin-side controls for tracking users and continuing conversations. It was designed as a lightweight support automation tool with resilient messaging behavior.

Key Highlights

  • Built bidirectional admin-to-user relay logic with persistent message-link mapping and active-user tracking.
  • Added broadcast confirmation, admin command panels, paginated user listing, and search-based user lookup.
  • Implemented user anti-spam rate limiting and exponential backoff for transient Telegram API failures.
  • Prepared the bot for long-running Windows deployment with startup and auto-restart scripts.
