Description

Movie Search Bot is a production-ready Telegram bot that searches configured channels, returns matching files through paginated results, and supports either polling or webhook-based deployment. It uses persistent Telethon sessions, SQLite user storage, and retry-aware delivery logic for stable long-running operation.

Key Highlights

  • Built configurable channel search with capped result sets, per-user caching, and paginated file selection.
  • Added rate-limited copy delivery, retry handling, and auto-delete behavior to improve Telegram UX and reliability.
  • Prepared deployment for Linux VMs with systemd, environment-driven config, and optional webhook support.
  • Separated secrets and runtime configuration into environment variables for safer production setup.
