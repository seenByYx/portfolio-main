Study Notes App

Academic resource platform for discovering, uploading, rating, and requesting subject notes

Tech Stack

Next.js React MongoDB NextAuth Google OAuth JWT

Description

Study Notes App is a role-based web platform built for students to access class and course notes, search academic resources, post comments, submit note requests, and manage uploads through owner and admin moderation workflows. The app combines modern Next.js UI with MongoDB-backed APIs and session-based authentication.

Key Highlights

  • Implemented owner, admin, and user roles with protected APIs for user management, uploads, comments, and moderation.
  • Built note search, request voting, ratings, open tracking, and comment threads to improve content discovery and engagement.
  • Integrated Google sign-in and session handling with NextAuth plus MongoDB persistence for account and role management.
  • Supports Drive links and structured note organization across classes, courses, semesters, and subjects.
