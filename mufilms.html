Description

MuFilms is a broader automation suite built around Telegram media workflows. It includes movie search bots, request and notification systems, structured series browsing, channel post formatting, rename utilities, and a resumable backup pipeline with Google Drive relay capabilities.

Key Highlights

  • Built multiple specialized bots for search, structured series browsing, channel formatting, caption cleaning, and file renaming.
  • Implemented SQLite-backed request tracking, live upload monitoring, and event-driven notifications for requested titles.
  • Designed a backup pipeline that tracked 272,917 processed message IDs and 50,830 existing filenames with resumable progress state.
  • Added recovery paths for flood waits, expired file references, and Drive-to-Telegram streaming workflows.
