MoneyBookBot

Telegram-based expense and transaction manager for lightweight personal finance tracking

Tech Stack

Description

MoneyBookBot streamlines day-to-day finance logging through Telegram commands. Users can add credits and expenses, view recent transactions, calculate totals, and manage entries through inline deletion flows. The bot is organized into modular handlers and database utilities for maintainability.

Key Highlights

  • Built modular command handlers for adding, viewing, deleting, and summarizing financial transactions.
  • Integrated SQLite persistence to manage categorized expense and credit records reliably.
  • Added admin-oriented broadcast features and configurable bot settings for operational flexibility.
  • Designed the architecture around reusable handler and utility layers to simplify future feature growth.
